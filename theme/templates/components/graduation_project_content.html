Automated Lesion Segmentation in Epilepsy

Graduation Project · Cairo University · July 2026

IEEE EMBC finalist 2 pipelines Bonn FCD II · n = 28

Built two deep learning pipelines for automated Focal Cortical Dysplasia (FCD Type II) lesion segmentation in 3D FLAIR MRI, supporting pre-surgical evaluation in drug-resistant epilepsy. One is a supervised nnU-Net approach that became an IEEE EMBC finalist; the other tests whether synthetic data can remove the field's data-scarcity bottleneck.
